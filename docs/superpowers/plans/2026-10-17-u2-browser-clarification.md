# U2 浏览器连续澄清与范围确认

依据已批准 #29/#31，基线 ad64f10；沿用用户确认的浏览器和公开 HTTP/TaskService 测试边界，不重复索要测试授权。

1. HTTP 回答操作：呈现已有协议字段，持久去重，按待答问题版本验证；在消费回答前占用单执行位置，后台调用现有 TaskService.answer。崩溃未知操作不自动重放。
2. 页面显示已知条件、问题、建议选项与自由输入，协议标识不作为用户输入。保留回答重试操作，刷新读取最新问题；沿用视图代次保护。
3. 浏览器连续三阶段以上澄清并实际查询；确认日期冲突、基期、范围接受/拒绝/无可用数据；公开接口补并发、重复与过期回答；独立 SQL 核对。
4. 真实模型带澄清诊断实验、类型检查、双轴子代理审查，修复发现后完整回归一次；归档、更新使用说明、提交当前分支。本轮未明确授权推送/关闭。
