# U1 本机启动与一次浏览器查询

执行依据：已确认规格 #29、任务 #30、用户 $implement 指令。基线 0ab2b0a。沿用已批准浏览器与公开 HTTP/TaskService 测试边界，本线程实施，末尾双轴子代理审查。

## 模块与接口
- metricguard/web.py：LocalWeb(service, port=0) 提供回环 HTTP 服务、允许的静态资源/API、单执行锁、持久操作去重和后台执行；公开地址 origin，start/close 生命周期。服务仍为长期唯一 TaskService 实例。
- metricguard/web_assets/：HTML/CSS/JS，表单、状态轮询、可复制的任务链接、纯文本安全结果；不做 U2–U5。
- metricguard/web_start.py：一条命令启动与配置前置检查；支持显式注册快照，以及可复现示例入口，不安装依赖或接受任意网页路径。
- tests/test_u1_web.py：公开 HTTP 行为，提供方受控、真实隔离查询；tests/test_u1_browser.py：真实浏览器完整查询和重新打开。
- docs/validation/u1-report.md 与归档：独立参考、红绿、真实模型、浏览器截图和完整回归证据；docs/local-ui.md：启动使用。

## 步骤
1. 红测试：提交同一操作两次返回同一任务，后台阻塞时另一操作拒绝且状态可读；实现公开 HTTP 接口与持久去重。
2. 红测试：非法快照/额外执行参数、来源与 Host、无凭据、非法日期、跨重启操作重放；实现配置与请求限制。
3. 红测试：浏览器实际提交简单查询、显示独立核查人数、刷新和重新打开同任务不再调用；实现页面和启动入口。
4. 真实模型+实际隔离查询复验，截图自审；类型检查、相关测试、双轴审查，解决发现后完整回归一次。提交本轮改动，不自动推送或关闭 Issue。

## 设计
采用浅蓝灰工作底色 #eef3f8、白色工作面 #ffffff、深蓝正文 #162f4c、蓝色动作 #2459a6、灰蓝辅助 #53677c、深红错误 #a32638。本地微软雅黑/系统无衬线，数字等宽；桌面左右工作区、小屏单列，左对齐、可见焦点、无外部字体或图像依赖。状态区先说明当前操作，不使用虚构统计卡、渐变或大幅营销标题。

## 审查重点
操作接受后页面断开不取消；同一请求持久去重，崩溃窗口不能自动重放；等待不占执行槽；浏览器不能改变镜像/预算/路径；凭据与异常信息脱敏；本地来源/Host 与 CSP；实际状态读取不改变执行预算。保留既有未跟踪设计文档，不混入产品实现提交。
