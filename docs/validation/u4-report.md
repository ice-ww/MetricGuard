# U4 分层报告与可定位证据

日期：2026-10-19。Issue [#33](https://github.com/ice-ww/MetricGuard/issues/33)，父规格 #29，基线 `5a9a960`。

## 交付与验收对应

- Web 报告只读已有发布版本，复用 readable 的结论、比较、单位、百分比/百分点和限制。不新增模型摘要、发布或查询调用。
- 默认显示结论、关键比较、原始/确认/实际窗口、基期、范围不足和未排除因素。支持/反对依据、完整事实、原始证据、完整推断、执行记录及完整文本按需展开。
- 点击 A 引用自动展开并聚焦具体事实，再点击位置聚焦原始证据行/列（行号从 0 起）。原始证据保留类型、参数、快照、截断状态及派生信息。
- GET /api/tasks/{id}/report 先检查 Web 所有权；不接受任意文件路径。失败、无报告和读取错误明确反馈；证据哈希不匹配时拒绝展示引用。
- 页面内容使用文本节点，不执行 HTML/Markdown 脚本。实际数据及问题含 img/onerror 标记仍为文字。

使用步骤见 [本机界面说明](../local-ui.md)。本轮没有实现 U5 关联重跑，没有修改业务层规则。

## 受控模型与独立参考

真实 Edge→HTTP→TaskService→SQLite/Docker。模型只在外部提供方边界受控。

1. 简单新增查询：独立 SQL 计数 1680；浏览器引用定位具体事实及原始单元格；查看前后任务完整状态相等。原始 channel 数据及问题中的脚本标记不执行。
2. A4 诊断：显示 Android/iOS 本期/基期和百分点比较，支持/反对依据可展开，未排除因素可见。逐条事实引用定位并匹配原值。
3. 正常播放对照：已核验双链路范围内未形成支持充分的异常候选；与查询事实、证据不足分别展示。此正常用例只检查已发布值与定位，未另做独立播放指标核算。
4. 数据不足：用户明确选择缩小范围，原请求 [2026-01-08, 2026-01-15) 与确认的 [2026-01-08, 2026-01-11) 默认可见；保留不能推广原范围及不等长窗口限制。
5. A4/不足用例的独立参考直接读取 users 注册本地日、sessions 活动本地日，用 D+1 集合计算分系统人数/留存，核对实际查询证据。
6. 公开接口验证跨任务、路径访问和错误 token 拒绝；等待无报告；实际检查点丢失后页面显示执行失败，不能假装已有成功报告。

## 红绿与测试记录

首条浏览器红测试缺少报告视图；实现引用后通过。三类诊断红测试缺少明确结果标签；补齐后通过。首次失败状态测试把连接失败的未知用量保护误作 failed，实际是预算保护 ended；改用真实检查点丢失验证失败状态，未改变产品规则。真实实验入口的可空 SQL fetchone 类型问题已修正。兼容性回归初次为 25 通过、1 失败：新增安全断言误用未转义字符串匹配 JSON 原始证据，纠正预期的 JSON 转义后复验。

超大整数边界：首次测试的 BIGINT 转换被既有 SQL 安全规则拒绝，去掉无关转换后实际复现原始单元格 9007199254740993 被浏览器显示为 9007199254740992。服务端增加精确单元格/元数据/执行记录文本，前端直接安全显示，不改变原始证据或计算。最终 U4 定向回归 **7 passed，0 failed，0 skipped**，73.07 秒；完整类型检查 94 文件通过，两个实验入口类型检查通过。首次全量 **516 passed、1 failed**，1454.35 秒。失败是已有 HTTP 来源拒绝测试偶发连接重置。普通 100 请求通过，但分段正文 10/10 复现连接异常；新增来源/token 分段红测试均失败。根因是提前拒绝后关闭带未读正文的连接；修复为只排空不超过 16384 字节的剩余正文，总期限 1 秒，不解析或执行拒绝内容。原失败用例及新增检查首次复验 5 passed，进一步覆盖半个正文后停止发送的期限行为；受影响传输回归 **14 passed**，79.34 秒，0 跳过。修复经子代理安全复查无阻断项。最终版本还通过 [真实结果只读重验](u4/final-display-recheck.json)：重新打开两条真实模型任务并逐条定位原始单元格，报告与任务状态完全不变，新增模型调用为 0。入口 `uv run python -m experiments.u4_recheck`。因产品传输代码发生必要修改，重新执行最终全量：`uv run pytest -q --junitxml=artifacts/u4-full-suite-final.xml`，**519 passed、0 failed、0 skipped**，1475.81 秒，退出码 0。所有失败与通过运行的 JUnit 原文和哈希见 [测试清单](u4/tests.json)，环境及冻结源码哈希见 [环境记录](u4/environment.json)。
