日期：2026-10-19。Issue [#34](https://github.com/ice-ww/MetricGuard/issues/34)，父规格 #29，基线 `30a5557403e9169195de7783a63b9eaae80da01a`。在线要求已核对，暂无评论。

## 交付

- 历史任务打开后显示中断、模型超时或失败说明。模型未知用量仍沿用服务的预算保护终态，另显示未完成分析和恢复说明，不把“已结束”当成成功。
- `POST /api/tasks/{id}/rerun` 仅接受操作标识，复用 TaskService.rerun 创建新任务及 parent 关联；复用单执行锁及持久化操作去重。原任务与证据不覆盖。
- “复制并修改”只填入旧问题、快照、明确日期与比较基期；用户确认提交后创建独立任务，不继承旧证据、结论或澄清答案。
- 服务持有者将失去执行确认的未完成操作记录为中断；回答检查点丢失等图执行前故障记录为失败。公开生命周期方法只记录已停止执行，不提供取消或续跑。
- 重跑响应丢失后，页面保存同一操作标识，刷新和重试不会重复创建任务。页面显示原任务链接与安全错误说明。
