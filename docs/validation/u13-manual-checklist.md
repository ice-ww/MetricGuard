## 启动与停止

在仓库 PowerShell 中，先按 [使用说明](../local-ui.md)准备依赖、Docker Linux 引擎、当前源码的固定镜像 ID，并在当前终端配置 `ANTHROPIC_AUTH_TOKEN`。不要将凭据填入页面或反馈。

```powershell
$env:PYTHONUTF8='1'
uv run python -m experiments.u6_manual --state-dir artifacts/u13-manual/state --port 8765
```

打开终端显示的 `http://127.0.0.1:8765`。复验恢复时使用相同地址、端口、状态目录和快照配置。端口占用可在首次启动时选其他端口；页面不能自动发现新端口。正常停止在终端按 Ctrl+C，等待执行结束和进程退出；关闭标签页不停止服务。此目录与旧 U6 人工记录分开保存，重启不会清除原任务。
