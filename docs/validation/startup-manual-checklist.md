# Windows 日常启动人工复验

对应 Issue #44 / #50。自动验证与本清单分别记录；未得到用户实际复验结果时，人工状态为待验。

1. 在项目根目录双击 `start.cmd`。首次选择 `existing` 与原任务目录，或选择 `new` 与明确的新目录；
   新目录可选择 `example`，已有数据选择 `existing` 并填写 `ID=PATH`。填写镜像、端口和模型地址，
   核对完整路径后输入 `yes`。确认窗口保持、页面自动打开。
2. 若当前窗口未继承 `ANTHROPIC_AUTH_TOKEN`，等待专用隐藏录入提示后输入凭据，
   确认字符不回显。不要把凭据写入反馈、截图或任务内容。
3. 关闭页面，确认终端仍在；从终端地址重新打开。按 Ctrl+C 正常停止，
   若有已接受任务，确认提示等待其结束。
4. 再次双击，确认复用配置和历史。可查看已有等待任务、已结束任务及报告，
   记录任务地址中的 ID，确认未变。无需为启动验收额外调用模型。
5. 原服务运行时再次双击入口，确认看到端口或目录占用提示，失败窗口保持可读，
   按键后退出，原服务仍可用。
6. 在终端运行 `.\start.cmd --configure`，查看修改前后内容后取消，
   确认下次仍沿用原设置。若明确改端口，使用提示的新地址。

反馈可用：“启动、错误可读、页面打开、停止、历史保留均通过”，或列出失败项与不含凭据的错误文本。
本清单只确认 Windows + Docker Desktop Linux 引擎体验，不代表其他平台新增安装体验通过。
