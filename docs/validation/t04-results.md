## 数值与口径

标准库标量 Wilson/Newcombe 与独立 statsmodels 显式方法，在空样本之外的64种全零、全成功、极小和极不平衡组合一致，最大绝对误差 `2.30926389122033e-14`（包含百分点差区间）。空样本保留 `null` 比例和区间。非法计数拒绝；重复ID、重叠用户、未知独立性、异质结构、采集不完整禁用区间并保留描述；重复用户相同结果去重计数，冲突结果拒绝。

18个真实 T01 开发数据库、两期共36次聚合，每次与独立 Python 用户集合/计数核对一致。基期、本期均按 Shanghai 注册自然日与成熟度截断；72个固定比较保留原始成功数与人数。A4标准化仅描述，A3同播放遥测差不使用独立二项区间。四个比较分层及生成模型依据见[冻结契约](../design/t04-statistics-contract.md)。

## 覆盖率模拟的限制

固定 NumPy 种子20261012，每组2000次，15组 Wilson 与4组 Newcombe。Wilson实测覆盖91.6%—100%；尤其 `n=100,p=.01`为91.6%，`p=.99`为91.85%，说明“名义95%”不是有限离散样本逐点保证。Newcombe四组分别94.6%、94.15%、95.15%、100%，均保留宽度和参数。**未把低于95%的结果隐藏或标为失败后重抽**，不以模拟固定参数覆盖率承诺任意参数/自适应诊断的覆盖。

所有区间输出包含探索性限制：单次名义95%，未校正自适应选择，不证明因果，不保证最终被选中诊断有95%可靠性。T04没有 Agent，`end_to_end_agent_false_positive_rate=null`；完整选择轨迹与流程误报须在后续集成/T20验证。规则、采样结构、数据规模或最终实现变化后需重新验证，不能继承本实验结论。
