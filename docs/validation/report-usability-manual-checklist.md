## 启动

Docker Desktop Linux 引擎运行，当前 PowerShell 已配置模型凭据。每次只启动一个案例：

```powershell
Set-Location 'D:\ai coding\metricguard'
$env:PYTHONUTF8='1'
$env:METRICGUARD_TEST_IMAGE='sha256:4cadf9b4afae2394df26a2d518ab7d68fbbc4e086081f4273c45410fae456cb0'
uv run python -m experiments.f6_manual --case A1
```

变化分析出现建议基期时选择 1。其他案例只替换 --case 值。数据为开发快照，日期结束日不包含。

## 检查项

| 案例 | 操作与验收重点 |
| --- | --- |
| A1 | 确认基期；第一行应直接出现 Android、版本 2.0。解释先于成段数值，版本 2.0 与对照版本的留存/崩溃数字及引用并列；没有对应基期的新版不能生成虚构的跨期差值。 |
| A3 | 确认基期；同分群观测完播率和独立进度完整比例并列，关键比较不需到 JSON 中寻找。 |
| A4 | 确认基期；Android/iOS 留存变化、百分点、结构占比及标准化对照可查，保留因果限制。 |
| simple | 直接看新增人数、日期、[A编号]。终端不出现 (#fact-...)；打开输出的 report.md，引用仍能跳到完整事实表。 |
| chain | 先选择 2 保留预设日期，再确认基期和可用范围；明确基期 7 天、本期 3 天。应说明总量不能直接比较增长，比率也不能自动认定可比。无支持充分候选时标题不伪装成候选解释或正常结论。 |
| coverage | 选择 2 保留完整请求范围；证据不足标题和具体缺口/下一步应清楚。 |
| clarify | 澄清时直接回车，复制打印的 Set-Location 和 & 开头两行，到另一 PowerShell 目录执行；应恢复同一任务，而非新建任务。凭据需在新终端中已配置。 |

检查重复说明是否明显减少、长段落是否仍难读、是否能仅凭正文知道对象/数字/比较日期。数字按三位小数展示，核算请用 publication.json/evidence.json 原值。
