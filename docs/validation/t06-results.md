语料有 6 份通用定义：新增用户自然日次日留存、完播率、有效播放率、每新增用户成本、每次日留存用户成本、首日崩溃受影响比例。每份包含分子、分母、维度、关联、自然日/完整性要求、误区。留存按注册归属、成熟新增 cohort；成本注册窗口一致、金额分、零分母 null；播放唯一实例去重、独立进度链路对照。

示例实测：`新用户次日留存` 精确采用 retention；`新注册用户第二天回来比例` BM25 采用 retention；`留存率` 澄清人群；`完播率有效播放率` 候选歧义；`用户满意度` 不支持；窗口缺失/倒置/相对时间字符串明确要求澄清。

边界：这是固定小语料和固定开发集上的检索验证，不能从 28/28 推断任意自然语言准确率。不执行业务 SQL，不证明查询已遵循定义；后续集成仍需核对采用定义、实际 SQL 与水位。语料只提供定义来源，不能单独支撑业务数字。开发集不是冻结集，不能复用于未见验收。
