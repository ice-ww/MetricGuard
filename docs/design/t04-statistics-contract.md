# T04 / V2 统计实验契约

本票仅验证统计计算与判定规则，不实现 `compute_stats` 产品工具、Agent、冻结验收集或其他任务。公开测试边界沿用已批准票中的“统计输入 → 效应、区间、适用性与判定”和可重复实验入口；测试不依赖内部函数或节点。

`BinarySample` 必须是非负整数人数，`0 <= successes <= users`，拒绝布尔值、浮点数和负数。`compare_users` 使用用户 ID 验证重复与交叠；同一 ID 的冲突结果直接拒绝，相同重复结果只计一个描述性用户并禁用区间。汇总计数接口 `compare` 无法从人数证明独立性，调用方必须显式声明 `independent=True`，并负责真实的完整性、去重和同质性依据。默认未知独立性拒绝推断。不得把这些布尔声明当作数据验证器。

单比例使用双侧名义 95% Wilson；本期减基期的差使用双侧名义 95% Newcombe hybrid score，展示百分点。实现采用标准库标量公式，独立参考为锁定的 statsmodels `proportion_confint(method='wilson', alpha=.05)` 与 `confint_proportions_2indep(method='newcomb', compare='diff', alpha=.05)`，不调用其 score inversion 分支，不输出 Newcombe p 值。

空样本、采集不完整、重复/重叠用户、不独立、异质或聚类结构均保留可核验计数和可计算的描述差值，但不给二项区间。全零、全成功可以计算非退化区间，不能解释为零风险/必然成功。A4 基期结构标准化点估计使用真实分层权重；不将派生量转为二项整数计数，其区间始终为空。A3 同一播放的采集与遥测不是独立样本。

冻结开发规则 `t04-v1`：业务阈值 5 个百分点，差值区间总宽度最多 20 个百分点；留存方向为下降，崩溃方向为上升。两期需均非空、完整、去重、无交叠，且独立同质 Bernoulli 模型可解释。无统一 `n>=30` 门；精度由区间宽度确定。以下为留存规则，上升方向对称，双向规则只有整个区间位于容忍带内才给有限“未达到标准”结论。

| 条件 | 状态 |
| --- | --- |
| 质量或模型门失败 | insufficient_evidence |
| 区间总宽 >20pp | insufficient_precision |
| 上界 <-5pp | anomaly_supported |
| 下界 >-5pp | below_anomaly_standard |
| 其他，包括恰好接触边界 | indeterminate |

`below_anomaly_standard` 只针对该指标/分群/窗口，不表示全局没有异常。`indeterminate` 不能合并为通过。所有输出保留点估计，即使精度或判定不足。

开发校准固定 seed 7、19、41，正常、A1—A4、证据不足共18个实例；基期 [2026-01-01, 2026-01-08)，本期 [2026-01-08, 2026-01-15)，Asia/Shanghai，使用 T01 成熟 cohort 查询和独立 Python 用户集合复核。四个固定比较为 Android organic 1.0 留存、Android paid 1.0 留存、Android organic 2.0 留存、Android 2.0 首日崩溃；对应基期使用同渠道 Android（当时均1.0），崩溃基期用全部 Android。用户独立伪随机流，无日/家庭/设备共享冲击；每个所选分层具有一致的边际概率。系统混合总计与 A4 标准化只作描述。

阈值候选3/5/8pp、精度候选10/15/20pp完整保留。5/20使18项强目标变化通过，正常12项误报为0，但其中9项仍无法判断；15pp只允许9项目标，8pp丢失3项。该选择是当前开发分布的业务约定，不是统计方法推导出的普适阈值。规则已在本票验收之前冻结；后续更改必须改版本、完整重跑并保留原记录，不根据冻结验收失败定向调参后仍称未见验收。

区间对象是潜在生成/业务过程，不是快照数字是否正确。每个输出均携带“单次名义95%、未校正自适应选择、无最终诊断95%保证、无因果证明”的限制。模拟覆盖率需如实报告，包括稀疏 Wilson 小于95%的情况。全 Agent 流程误报和选择轨迹留待集成/T20实测，T04不提前声称通过。
