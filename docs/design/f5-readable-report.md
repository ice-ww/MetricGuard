# F5 可读报告与终端展示

Issue #27，审查基线 a54dc4c；沿用已确认 TaskService 和终端测试边界。

`TaskService.export_report(task)` 对终止任务构建已校验发布结果，返回简明正文及完整 Markdown、原始证据文件路径。保存目录为状态目录下 `reports/<task>/<publication_id>/`，包含 report.md、publication.json、evidence.json、task.json。终端 chat/resume 直接展示相同正文和文件路径。`report` 原有结构化接口不变。

正文按实际分群和比较窗口合并已发布数值断言。简单查询给出数值；诊断展示候选、支持依据、反对证据与对照、未排除因素、因果限制；系统结构/播放诊断补充经验证的结构标准化、占比和独立进度比率。正文最多显示每节12个分组，超过时明确提示查看完整事实表，不隐含未展示分组不存在。

正文中的 A 编号链接到完整事实表，表中列出 evidence_id/rows/零起点行号/列名；派生结果还可在同目录 evidence.json 的 parameters.provenance 查到原始来源。所有归档包含发布后派生证据。报告只读取 publication 校验通过的数值断言，不把原始空值发布为零、不把未经验证的模型文字补成新事实。原始空值保留在 evidence.json。

比例由原始比率仅在显示时乘100并保留三位小数，人数保持原值，成本按源字段的“分/人”，支出按“分”。前后期比率并列展示，不把百分比或百分点差值互换。未知 SQL 指标不会从列别名猜测单位；正文注明业务口径仍需核验。原始值不随展示取整变化。

导出不调用模型或隔离查询，不改变预算。它复用经过校验的事实和程序诊断，机械引用有效不等于已证明业务口径、语义解释或因果。历史任务原报告状态不改写；导出文件按发布标识保存，同一发布再次导出会刷新展示文件。验收原始记录另行归档保留。

F4 缩小授权说明位于判断正文之前。不等长渠道窗口明确显示两期天数和不可直接判断新增计数增长的原因。

验证：[F5 验证报告](../validation/f5-report.md)。

模型 stop 待查问题可能包含未核验事实，只保留在 task.json；停止原因不重述用户原问中的断言。
