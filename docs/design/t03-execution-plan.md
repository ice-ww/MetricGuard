# T03 资源验证实施记录

范围为 Issue #4；审查基线 `b88d61f`。与 T02 共用已验证的隔离启动和查询入口，增加宿主期限监督、受限抓取/编码、资源故障与回收实验。测试边界沿用已批准票据的公共查询入口及独立隔离故障入口。

SQL 期限从 worker 核验完成的 ready 握手后开始，宿主发送请求前记时，覆盖解析、执行、抓取、序列化、传输、宿主解码及 worker 退出。默认 5 秒，可缩短而不能放宽。超期结果不进入证据；启动、终止和回收另有时长，整个调用活动耗时也保留。

保留 T02 的只读快照和数据隔离配置。正常结果按独立手算 10+20+7=37 核验。资源边界取固定候选值后，在实际容器中验证：512 MiB cgroup、无 swap、1 CPU、64 PID、16 MiB tmpfs、DuckDB 128 MB 且禁用 spill、1000 行、64 列、64 KiB 单元格 JSON、1 MiB 协议。

先观察测试失败，再实施限额与监督；用真实 OOM、ENOSPC、崩溃、带子进程超时及高代价 SQL 验证，保留失败记录。子代理实现独立验收套件；另一子代理审查并复跑 T02 权限套件。最终配置、失败类型和终止延迟写入实测报告，不把候选值视为普遍最佳参数或严格实时保证。
