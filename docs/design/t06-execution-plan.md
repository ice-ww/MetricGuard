# T06 检索与澄清验证

范围仅 Issue #7。公开实验边界为 `retrieve(question, window)` 返回采用/澄清/不支持、Top 3、采用的完整定义与版本，以及可重复运行的实验报告；不实现 Agent 节点、任务持久化或运行预算。

1. 先用公开检索入口验证精确别名与完整定义（缺失模块 red → 1 pass）。
2. 增加人群澄清与不支持时间口径（错误 adopted red → 修复）。
3. 在评分实验前写定开发查询标签，分 calibration 与 verification；只使用前者选择全局分词/阈值/分差。verification 已在开发测试中执行，因此整个集合明确属于开发回归，不能声称未见冻结集。
4. 全量网格比较 unigram/bigram × 阈值 1、2、4、6、8 × 相对分差 .05、.15、.3、.5。先最大正确数；同分选择 bigram、更高阈值、更高分差。该规则对所有问题统一应用。
5. 用独立扫描器与 50 位 Decimal BM25 核对 Top 3 和数值；核对水位、成熟性、固定归属与去重等语料口径对齐 T01/GLOSSARY。
6. 补充缺少留存期限和非法时间窗的失败测试，实跑并保存全部结果。

分词固定 NFKC、lowercase、中文连续字符双字、ASCII 单词；不动态调用服务、不下载词典。BM25 仅索引名称、别名、短定义；完整口径随采用结果输出。显式人口/留存期限规则先于模糊相似度，人群不明时不能猜成新增。明确相对时间不自动推断为当前日期，调用者必须提供排他 ISO 日期窗口；成熟性/数据水位核验属于下游查询，检索定义会明确要求。
