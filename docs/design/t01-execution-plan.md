范围遵循已批准 Issue #2，仅开发数据与口径实验，不接入 Agent、SQL 安全执行器或冻结验收集。

测试边界为可重复的实验入口及其公开快照/核验输出：真实 DuckDB 查询与独立 Python 集合计算交叉核验，再用人工可复算的小样例固定预期，避免两套逻辑同时错而不被发现。

使用固定版本锁文件；公开目录只包含业务快照，私有目录保存场景配置、预期、比较结果和 pending 人工核验记录。仅逻辑内容哈希承诺复现，不承诺 DuckDB 二进制字节完全相同。
