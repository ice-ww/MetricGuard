# 在模型之外强制执行查询与预算边界

SQL 安全同时采用 AST 对表、函数和语句的校验、查询进程的数据访问隔离、外部访问限制，以及由程序强制执行的超时和资源预算；具体配置仍需实现验证，不能把语句形式检查等同于安全边界。
独立安全测试覆盖文件访问、系统元数据、非授权函数、多语句和资源耗尽等情况，测试规模不受约 40 个业务任务限制。
预算由程序维护，模型不能通过重新规划重置；耗尽时返回已有事实和未决问题，而非强行归因。

## 初始运行参数

- SQL 初次执行失败后最多修复两次，共三次尝试；每次尝试都占用全局调用预算。
- 工具总调用上限以可配置的 12 次作为试运行值，检索、Schema 查询和失败调用均计入。
- 图表后处理最多生成三张图表，不占用上述诊断工具预算。
- 这些数值尚未经过运行验证，可调整数值，但调整不得绕过程序执行的权限与预算边界。
