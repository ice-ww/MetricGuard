# 用户级二元指标统计研究

研究日期：2026-10-12。范围：P0 留存及新增用户首日崩溃受影响比例；只研究，不实现产品或实验代码。本文的“已核实”指一手资料核实，“建议”指项目设计建议，“待验证”不代表已完成运行测试。依据为 `GLOSSARY.md`、`docs/design/p0-contract.md` 及 ADR 0004、0006、0007；不修改已经确认的设计。

## 结论与 P0 建议

建议单比例使用双侧 95% Wilson 区间；两个独立用户样本的比例差使用双侧 95% Newcombe hybrid score 区间，差值统一为“本期减基期”，展示单位为百分点。调用方法与依赖版本显式固定，不依赖库默认值。它们是有条件的模型推断，不是数据质量或因果保证。

P0 先支持口径明确、用户去重且独立性假设可说明的比较。样本为空、采集不完整、用户重叠或依赖结构不受支持时保留可核验的描述性计数，禁用不适用的区间。Agent 自适应下钻所得区间标记为探索性、未经选择校正；不承诺整个诊断具有 95% 覆盖率。

## 1. 先确定统计对象

**项目解释与建议：** 次日留存以用户为单位，一个成熟注册用户仅有一个 0/1 结果；首日崩溃指标同理，同一用户十次崩溃也只计一个受影响用户。分别累计窗口内成功人数与新增人数，计算 `sum(successes) / sum(users)`，不对七个日留存率取无权平均。用户不跨注册 cohort 重复，但这只排除一种依赖，不能证明用户之间独立。

两个样本独立还要求没有跨组共享的随机冲击或关联采样等依赖。合成器若设置日级随机冲击、家庭/设备关联或固定异质概率，应在统计契约中声明；不能看到用户 ID 不重叠就自动批准二项推断。官方独立比例接口明确假设两个独立二项样本；聚类/重复测量数据属于另一个模型问题。[statsmodels 独立比例区间](https://www.statsmodels.org/stable/generated/statsmodels.stats.proportion.confint_proportions_2indep.html)、[GEE 官方说明](https://www.statsmodels.org/stable/gee.html)。

**全量快照的含义：** 对快照内所有用户计算出的比例是该快照的确定事实，没有抽样误差需要修补。只有将用户视为潜在随机业务/生成过程的实现时，区间才描述该过程参数的估计不确定性；它不覆盖埋点丢失、口径错误、未来分布漂移或注入原因的不确定性。这是将二项模型用于本项目的解释约束，不应把“95%”写成该快照数字有 95% 概率正确。NIST 将比例区间的对象定义为总体比例参数。[NIST 比例区间](https://www.itl.nist.gov/div898/handbook/prc/section2/prc241.htm)。

**P0 边界建议：** 重叠窗口、同一用户前后状态、同一批用户的崩溃与留存两种结果，均不能直接当作两个独立样本。配对比较需保留用户级联合 2×2 计数；聚类推断需保留组标识并采用相应方法。P0 暂不实现配对区间或 GEE，返回“当前统计方法不适用”。播放级完播与独立遥测的差异仍按 `play_id` 做证据交叉核对，不能假装成独立用户二项比较。[配对比例官方接口](https://www.statsmodels.org/dev/generated/statsmodels.stats.proportion.confint_proportions_paired.html)、[GEE 官方说明](https://www.statsmodels.org/stable/gee.html)。

## 2. 方法选择、边界与库支持

| 对象 | 已核实的支持 | P0 建议 |
| --- | --- | --- |
| 单个比例 `x/n` | `proportion_confint` 支持 Wilson、正态近似、Clopper–Pearson 等 | 显式 `method='wilson', alpha=0.05` |
| 独立比例差 | `confint_proportions_2indep` 支持 Newcombe 与 score；差值定义为 `p1-p2` | 显式 `method='newcomb', compare='diff', alpha=0.05`，本期为第一个样本 |
| score 差值区间 | 通过 score inversion 计算；`correction=True` 对 score 使用 Miettinen–Nurminen 小样本方差修正 | 作为交叉验证候选，不作 P0 默认 |

来源：[单比例 API](https://www.statsmodels.org/stable/generated/statsmodels.stats.proportion.proportion_confint.html)、[独立比例差 API](https://www.statsmodels.org/stable/generated/statsmodels.stats.proportion.confint_proportions_2indep.html)。研究时 stable 页面标题为 0.15.0；独立比例 API 标记为 experimental，默认值可能改变。页面版本不是本地依赖版本，实施时仍需锁定并记录实际包版本。

**为什么不用普通 Wald：** 它在 `x=0` 或 `x=n` 时会产生零宽区间，而 Wilson 由 score 检验反演，边界仍有不确定性；小样本或极端比例下，普通对称正态近似可能不准确。[NIST 比例区间](https://www.itl.nist.gov/div898/handbook/prc/section2/prc241.htm)。

**方法不能混淆：** Newcombe hybrid 把两个 Wilson 区间组合成差值区间，并不等于直接相减两组区间端点，也不等于 Miettinen–Nurminen score inversion。官方源码也明确不提供 `newcomb` 对应的假设检验实现；不能伪造“Newcombe p 值”，更不能由两个单比例区间是否重叠判断差异。[statsmodels 比例源码](https://www.statsmodels.org/stable/_modules/statsmodels/stats/proportion.html)。

**已核实的版本风险：** 官方问题 #10269 报告 0.14.6 中 score 的非零差值约束计算存在系数错误，可能影响差值区间；该问题于 2026-09-29 由 #10270 关闭。此信息不能证明任一已安装发行包包含修复，也不能据此断言所有版本仍有缺陷。启用 score 前核对锁定发行版并独立验证；Newcombe 的实现走另一条分支。[问题与修复记录](https://github.com/statsmodels/statsmodels/issues/10269)、[官方源码](https://www.statsmodels.org/stable/_modules/statsmodels/stats/proportion.html)。

**项目边界处理建议：**

- `n=0`：比例与区间均不可计算，不能返回 0%。`x<0`、`x>n`、非整数计数：拒绝统计输入。
- `x=0` 或 `x=n` 且 `n>0`：允许 Wilson/Newcombe 计算并保留边界标记；零事件不等于零风险，全成功不等于成功概率为 1。
- 稀疏数据：不把“可计算区间”当作“足够支持诊断”。保留计数和精度限制；不临时切换到更好看的方法。Clopper–Pearson 可作单比例边界交叉检查，但不是两比例差的直接替代。[Clopper–Pearson 文档](https://www.statsmodels.org/stable/generated/statsmodels.stats.proportion.proportion_confint.html)。
- 比率在基期为零时不可计算；P0 主要报告百分点差，不通过加伪计数改变业务事实。
- A4 的基期结构标准化留存率是加权派生量，不能把它硬凑为整数 `x/n` 使用上述区间。P0 可准确报告点估计，派生量区间另作技术验证。

## 3. 数据充分性与“没有异常”

**已核实：** 统计显著性不衡量效应大小或业务重要性；结论不能仅由 p 值过线决定。样本设计应从所需精度出发，分层时还要考虑各层所需样本。[ASA 原始声明](https://www.amstat.org/asa/files/pdfs/p-valuestatement.pdf)、[NIST 样本量设计](https://www.itl.nist.gov/div898/handbook/ppc/section3/ppc333.htm)。

**可实施建议：** 每个指标预先定义业务方向、变化阈值 `δ`（百分点）及精度要求 `w_max`。另有硬性可用性条件：相关链路齐备、口径一致、用户去重、样本非空、比较方法适用。允许报告区间，但只有通过质量门且区间宽度达到冻结要求时才赋予足够精度标记。不把 `n>=30` 或成功/失败次数均大于 5 当作所有指标通用的充分性证明；具体样本数需根据基准率、阈值和正常波动校准。

以“本期留存下降”为例，令 `d=p_current-p_reference`、区间为 `[L,U]`：

| 条件 | 建议表述 |
| --- | --- |
| 口径/完整性/适用性不通过，或精度不足 | 证据不足；仍可列已核实的描述性事实 |
| `U < -δ` 且精度条件通过 | 区间支持下降超过业务阈值；仍不证明原因 |
| `L > -δ` 且精度条件通过 | 当前证据未支持达到预设下降标准；仅针对这一指标、分群与窗口 |
| 区间跨越 `-δ` | 无法确定是否达到业务下降阈值 |

这是项目待校准的保守报告规则，不是统计库默认功能。双向异常应预先声明 `[-δ,+δ]`，只有区间整体落在容忍带内才可作“未达到双向变化标准”的有限表述；区间覆盖零本身不足以证明等价。点估计已达到阈值但区间不够确定时，应同时展示观察变化与不确定性，不能隐藏事实。自适应选中的区间还须附加下节限制。

## 4. 多次比较与动态下钻

**已核实：** 对预先定义的检验族，Holm 控制族错误率，并允许任意依赖；BH 控制错误发现率，常用保证需要独立或适当的正相关条件；BY 可处理更一般依赖。错误发现率是拒绝结果中错误比例的期望，不能解释为每个结论的错误概率。以上都以输入 p 值有效为前提。[R 官方 p.adjust 文档及所列原始论文](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/p.adjust.html)。

**适用于本项目的推论：** Agent 看过结果后选择渠道、版本、日期甚至新指标，产生数据驱动的假设；只把最终几个 p 值做 Holm/BH 不能自动修复这种选择偏差。记录所有比较是审计必需项，却不充分保证统计有效。自适应数据复用有专门理论与控制方法，不能把常规多重校正当作通用补救。[Dwork 等原始研究](https://arxiv.org/abs/1411.2664)、[自适应 holdout 复用研究](https://arxiv.org/abs/1506.02629)。

**P0 建议：**

1. 主要输出效应与区间，不增设按 p 值排序的“最显著根因”。所有动态下钻区间标记“单次比较的名义 95% 区间，未校正自适应选择”；不得声称最终被选中的区间仍有 95% 覆盖保证。
2. Trace 保存尝试过的指标、分群、窗口、顺序、样本数、方法及结果，也保存失败和无明显变化的比较。已看过的数据不能通过新任务重命名为未见数据。
3. 若要发布固定比较族的显著性结论，事先冻结完整族和检验方法，对全部有效 p 值作 Holm；不要只校正报告中留下的项。BH/BY 暂不作为 P0 默认。
4. 若要确认探索所得假设，可另用事先隔离且此前未查看的数据，仅做冻结后的验证；P0 尚无此机制时保留探索性措辞。固定正常/异常生成分布上的端到端误报评测有用，但不能替代任意自适应分析的理论保证。

## 5. 实施前验证清单（本次未运行）

| 验证项 | 所需证据 |
| --- | --- |
| 方法实现 | 锁定包版本；与独立参考公式/参考软件比较 Wilson、Newcombe，不能复用同一封装互相验证 |
| 边界数值 | 空样本、全零、全成功、极小和极不平衡样本；检查区间有序、有限、合法且方向一致 |
| 口径 | 重复会话不会扩大人数；缺失日不补零；仅成熟注册用户入分母；重叠用户触发不适用 |
| 统计假设 | 文档声明条件独立/异质性/日级冲击；不满足二项模型时不给虚假精确的区间 |
| 参数冻结 | 在开发集选择 `δ`、`w_max` 与样本设计；报告覆盖表现、宽度、误报和证据不足比例，不只优化异常命中 |
| 自适应风险 | 正常实例走完整 Agent 流程评测误报；列出选择轨迹；不以一个固定检验的表现替代流程表现 |
| 输出约束 | 明确观测百分点差、方法、名义置信水平、推断对象、探索性标记与质量限制；不能出现“95% 因果可信度” |

依照当前契约，这些验证应在冻结验收前完成。本研究不改变 24 个任务和三轮验收门，也不提前承诺某个数值阈值可以满足它们。
